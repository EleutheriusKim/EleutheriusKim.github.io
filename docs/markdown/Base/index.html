체크박스​

리스트와 함께 사용하셔야 합니다.

대괄호안에 공백(space)가 있으면 uncheck, x 혹은 X가 있으면 check

- [ ] 체크박스1
- [ ] 체크박스2
- [x] 체크된 박스 1
- [X] 체크된 박스 2
